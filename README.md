# Cámara en tercera persona

En el siguiente proyecto se realizó la exploración de Cinemachine para la creación de una cámara en tercera persona que siga al jugador.
Adicionalmente, se implementó el efecto de X-ray para poder ver al personaje incluso si una pared u otro objeto está de por medio entre la cámara y el jugador, solucionando un problema bastante común durante el desarrollo de una cámara que sigue al jugador en un entorno 3D.

## Controles
- WASD - moverse
- Barra espaciadora - saltar
- Esc - salir
